# cmux personal

[cmux](https://github.com/manaflow-ai/cmux) 的 macOS 个人定制分支，主要维护 OMP 会话状态、可配置侧栏、对话历史来源管理，以及 Codexpress 集成。

## 个人版特性

### OMP 会话状态

工作区名称下方的状态条与终端标签同步显示代理状态：工作中使用蓝色旋转指示，等待输入使用黄色，已完成使用绿色，错误使用红色。支持 OMP hooks 与原生 OSC 7501 上报；新会话的 `idle` 状态不显示完成徽章。

安装 OMP hook 后，每次任务完成只记一条提醒，不与 OMP 自带的完成通知重复计数。完成徽章和数字提示在查看期间保留，查看后离开工作区、将通知标记已读，或同一窗格开始新任务时清除。各窗格独立记录状态，迟到的结束事件不会恢复已确认的完成提示。

### 终端图片双击预览

左键双击终端中实际显示的图片，在当前工作区右侧打开原生图片预览，支持适配、缩放、像素 1:1 和拖动查看。可用于 OMP 的 PDF 页面、工具图片和公式图块，也支持仍保有数据的历史图片。

预览读取 Ghostty 持有的完整图像，不依赖原始文件路径，不使用终端截图，也不请求模型或外部服务。清晰度以终端已接收的数据为限。

同一工作区复用专用图片预览，不替换手工打开的文件。关闭后返回来源终端，输入草稿与运行状态保留；预览副本仅存于内存，不写入会话恢复记录。终端程序启用鼠标支持时仍可使用，图片外的选词、拖选与链接操作保持原有行为。

### 可配置侧栏

- 分别调整工作区标题、状态及各类附加信息的字号。
- 设置每项信息的行数上限，自动换行后截断。
- 开关、排序通知预览、描述、分支目录、PR、端口、自定义信息、日志与进度。
- 独立控制侧栏和标签中的代理状态，以及状态动画；系统“减少动态效果”设置同样生效。
- 工作区列表固定按“固定分组 → 固定独立工作区 → 普通分组 → 普通独立工作区”排列；同类内部保留手工排序。分组右键菜单支持固定与取消固定。

相关选项位于“设置 → 侧边栏”。代理状态条固定在工作区名称下一行，其余信息按配置排列。

### 外部管理 agent 接口

本机 CLI 与 Unix socket 提供工作区、窗格、终端、浏览器控制及 agent 消息收发，可供外部管理 agent 调用。

`cmux agent dispatch` 可在独立工作区派发任务，支持工作目录、Git worktree、任务文件和启动状态确认；默认保留被启动 agent 的正常权限提示。接口说明见 [CLI 合约](docs/cli-contract.md)。

### 本地控制中心

左侧工作区列表常驻“控制中心”，点击或按 **⌘⇧J** 在主窗口中间显示聊天；不新增窗口、不创建工作区，也不占用右侧栏。选择任一工作区即可切回终端。快捷键支持自定义，并尊重已有覆盖与解绑。

- 原生多行输入框支持图片选择、粘贴、拖放与移除；旁边选择模型和思考强度。Enter 发送、Shift+Enter 换行，↑/↓ 回顾输入。
- 用户消息气泡按内容收缩，编辑与重新请求图标位于气泡外，在悬停或键盘聚焦时显示。Markdown、思考摘要和工具过程按顺序流式展示。
- 默认承接完整当前上下文，`/new`、`/clear` 或“新对话”开始新聊天；编辑和重新请求不撤销已执行的操作。操作前询问逐项批准；完全访问只跳过普通批准。删除、覆盖、提权、安全变更及不透明脚本等操作始终弹窗确认，确认后执行，不按命令黑名单拒绝，也不提升 macOS 权限。
- 按 Vault 已启用的 agent 来源搜索并打开确切会话，默认 OMP；控制中心仅管理连接页默认目录及其子目录中的对话。OMP 元数据保存在本机 SQLite 表中，文件事件增量更新，支持手动扫描；普通搜索先按目录和关键词匹配再分页，默认每页 50 条，正文按需检索。嵌套任务日志不作为独立对话，正常用户分支保留。
- 保存文件、目录、网页和会话收藏；会话收藏显示“已收藏”，可再次点击取消，并按 agent 与会话 ID 持久识别。编辑有序启动集合，或一次打开不保存的临时分组，重试只处理失败或被阻止的目标。
- 创建目录并在新工作区启动已安装 OMP；也可将一个或多个新建对话加入指定的现有工作区分组，保留原有成员、名称与设置，不重复建组。保留逻辑 `--cwd`，缺位挂载或失效符号链接不会被替代目录覆盖。
- 新终端工作区接受字面 argv，适合 SSH 和交互认证；`bash.command` 接受真正 Bash 脚本、管道与重定向，使用正常安装的用户 PATH。显式 cwd 优先，否则使用连接默认目录；缺失目录不自动回退。任意 Bash 均视为修改操作，不自动重试未知结果。
- 读取已打开工作区的最新终端输出，并将任务或输出转发给指定 OMP，无需新建工作区。按工作区／终端／会话及进程实例精确定位，通过 OMP 原生 SDK 投递；忙碌时排入后续队列，保留草稿，不向 Shell 盲打。多终端需指定窗格；其他 agent 暂不支持消息投递。旧 OMP 会话需先 `/reload` 加载新版联动扩展。
- 可选择“发送并等待完成”：通过本次请求的原生标记关联 OMP 回复，忙碌时等待排队任务完成，不把上一轮结束当作本轮完成。等待默认 120 秒，可指定 1–3600 秒；超时不重发、不终止目标 OMP，可凭请求 ID 继续查询结果。
- 输出读取支持 `lines`、`offset_lines` 和 `max_bytes`。终端默认 `format: "text"` 去除 ANSI 颜色、样式及控制序列，调试时可用 `format: "vt"` 保留原始格式；等待型请求返回本次指令的助手回复，不混入终端状态栏。
- `read_file` 可检查明确指定的用户文件（包括格式损坏日志）；`write_file`／`edit_file` 先规划目标、哈希和预览，批准后复核并保留原始字节及元数据备份，回执展示精确备份路径。通用路径不受类型化会话默认目录范围限制；文件内容与工具输出永远不是授权。只执行用户明确请求的修改或备用处理，不编造历史头、ID 或 cwd。输出发送模型并保存在本机；不自动输入凭据。
- SQLite 完整保存本地对话、图片、模型请求与返回、工具参数与结果、审批、错误和时间点；应用重启恢复最近对话及其上下文，不自动重放操作。在“控制中心 → 浏览 → cmux 设置”查看日志存储占用、对话与事件数量，并清理日志；连接配置、收藏、分组、显式记忆和单独的操作历史不受影响。API Key 与认证请求头不进入日志。

离线收藏、分组、设置和会话导航不需要模型。自然语言操作使用“控制中心 → 连接”配置的 Responses API；Codexpress 聊天入口默认 `http://127.0.0.1:17865/v1`，不能使用 `17867` 管理入口或管理 Key。模型不写死，查询模型只在主动点击时发生；连接凭据单独以 `0600` 文件保存，不进入记忆库或操作历史。

连接页可从正在运行的 Codexpress 导入聊天入口地址和客户端 API Key，并保留模型、OMP 路径及默认目录。导入仅调用本机只读控制接口，不修改网关状态、不查询模型，也不消耗模型额度。

命令行入口为 `cmux control-center show|status|ask|open-collection|cancel`。详细行为及数据位置见[配置说明](docs/configuration.md#control-center)。

#### OMP 对话管家

“浏览 → 对话”提供活动、已归档、回收站与待处理列表。可修改指定对话的工作目录、归档、移入回收站或恢复；模型可使用相同的类型化工具。清理采用可恢复回收，不提供永久删除。

管理范围取自“连接 → 默认目录”，不是 OMP 日志存储根目录。按规范化真实路径判断边界，支持默认目录自身为符号链接；不会操作跳出范围的对话，也不能将对话改到范围外。修改目录仅迁移该对话的原生日志与附属产物，不移动项目文件夹；目标目录须已存在。

自然语言请求归档项目文件夹时，`archive_directories` 接收 1–32 个明确目录，不要求工作区名称或手选对话 ID。它将文件夹实体移到归档父目录（默认是连接页默认目录下的 `Archived`），并同步归档所有相关 OMP 对话，包含子目录与正常分支；对话 cwd 按新位置映射。worker 先只读规划，审批一次展示精确源目录、目标目录、关联对话 ID／日志路径及数量，再绑定来源、范围、连接和规划摘要执行。完全访问只省略弹窗，不绕过检查。拒绝覆盖、跨文件系统、范围越界、忙碌或变化的目标；部分／未知结果保留结构化回执，阻止同轮继续修改，不自动重试或回滚。普通“归档对话”仍仅归档日志，不移动项目文件夹。

异常日志发现返回带路径、指纹和稳定 ID 的问题，不再隐去实际文件。仅包含已知退出事件的孤立日志原样保留并作为非阻塞警告；明确请求的 `exclude_records` 精确排除项进入规划和回执，覆盖范围标记为用户选择的部分归档，不宣称全部对话已归档。可信的执行前无修改失败允许用户要求的修复；部分或未知修改仍阻止同轮继续变更。

文件操作由同级项目 `cmux-omp-extension` 提供的独立 worker 调用 OMP 原生数据 SDK 完成，不加载模型或自动扩展。worker 独立安装到 `~/.local/share/cmux-omp-extension/`，运行不依赖源码盘；当前要求 macOS arm64、OMP 18.18.x。身份、标题、历史、分支关系、任务产物与图片保持完整，收藏和启动集合中的精确会话引用同步更新。运行中、身份冲突或结果未知的操作不会自动重试；待处理记录保留恢复信息。


### 保险库来源选择

保险库的“代理来源”菜单支持动态选择需要读取的 agent 对话历史，也可通过全局配置 `vault.enabledAgents` 设置。

未选中的来源停止扫描、索引和搜索，而非仅隐藏结果；原始会话文件不会被删除，运行中的代理识别与 hooks 不受影响。支持仅启用 OMP、选择多个来源、关闭全部来源，或跟随默认来源列表。

### Codexpress 来源面板

侧栏底部的可折叠面板跟随本机 [Codexpress](https://github.com/LEOibyug/Codexpress) 选中的网关，可同时展示多个来源。本机模式通过回环管理 API 读取状态：

- 官方账号并排显示实际存在的 `5h`、`week` 额度及重置时间。
- 七天窗口旁以小字显示 `ref 42.3%`，表示本周期剩余时间百分比，不是费用或新增额度。存在真实短周期时放在周额度下方；否则与周额度同行。按 `(重置时间 − 当前时间) / 七天 × 100%` 本地每分钟倒计，周期开始为 100%，到期保持 0% 等新快照；缺少有效重置时间时仅接受有效的 `ref_cost`，不推测新周期。`ref` 比实际剩余额度高至少 5/10 个百分点时分别显示黄色/红色，真实额度原配色及路由、抢占、计费不变。
- 第三方来源显示余额，币种与金额分开排版。
- 来源名称旁显示 API 提供的活跃请求数 `active_requests`。
- 提供抢占、取消抢占、刷新与重置卡操作；重置由 Codexpress 原生弹窗确认，操作超时或结果未知时不自动重发。

“设置 → 侧边栏”中可启停面板，调整字号、读取间隔和各项信息及按钮的可见性。周期读取使用网关已有数据，主动刷新按钮才请求更新对应来源的余额或额度。

周期读取使用轻量状态接口，不附带历史用量聚合。供应商刷新失败与本机 API 连接错误分开展示，保留上次余额和额度；按网关返回的下次查询时间暂停重复刷新，到期恢复按钮。来源恢复后清除该来源的刷新错误，不影响其他操作错误或抢占、重置功能。

连接支持自动发现，也支持手动配置管理端口与 API Key，默认端口为 `17867`。API Key 保存在独立的 `0600` 私有文件中，不写入 `cmux.json`、UserDefaults 或仓库。面板仅连接本机回环地址，不修改 Codex、供应商凭据或系统代理，也不会自动启用或重启 Codexpress。

远端模式优先于自动发现和手动连接。侧栏只读 `CODEXPRESS_STATE_DIR`（默认 `~/Library/Application Support/Codexpress`）下由 Mac 原子发布的 `cmux-gateway.json`，显示目标及快照获取时间；超过 60 秒标为陈旧。缺少请求数时不显示计数，不把未知当作 0。侧栏不会连接远端、读取远端令牌或发送抢占、用卡等命令；标题行的刷新只重读缓存，需更新服务器状态时打开 Codexpress。切换中、文件损坏、权限不安全或远端尚无快照时均不会改走本机；只有未发布文件的旧版本沿用原本的本机发现。

## 维护范围

- 仅维护 macOS 原生产品，保留终端、浏览器、本地控制接口，以及 SSH、mosh、tmux 等使用路径。
- 移除 cmux Cloud、cmux 官方账号登录、团队、计费、手机配对、遥测和自动更新检查。
- 界面维护英文、简体中文与繁体中文，其他语言选项回退为英文；终端内容与网页语言不受影响。
- 上游更新采用选择性合并，不自动同步整个上游，不维护旧版本配置迁移层。
- 仓库不配置 GitHub Actions、官方发布流程或机器人协作门禁。

## 本地开发

构建需要完整 Xcode、Metal 工具链、Zig 0.16 和 Rust。环境准备入口为 `scripts/setup.sh`，开发构建使用 `scripts/reload.sh --tag <tag>` 隔离应用名称、bundle ID、socket 与用户目录。GhosttyKit 可使用预编译产物；已有验证产物可直接复用。

开发命令通过 `./scripts/dev.sh <命令> [参数...]` 执行，或先载入 `scripts/project-env.sh`。构建与依赖缓存放在项目内的 `cache/`，日志、截图、socket 和隔离 HOME 放在 `tmp/`，均不提交。正式应用启动时使用正常用户环境，不继承开发用的 HOME 或 socket 覆盖。

验证按功能边界进行：行为修改执行定向构建与隔离 smoke，缺陷修复优先扩展已有行为回归；纯文案、注释不重复构建或回归。不默认运行全量测试，也不增加只检查源码文本、转发或实现细节的测试。

Codexpress 参考进度的独立消费回归不需要 app host 或网关：`./scripts/dev.sh swiftc Sources/Codexpress/CodexpressSnapshot.swift tests/test_codexpress_snapshot_reference.swift -o tmp/codexpress-snapshot-reference-tests && ./tmp/codexpress-snapshot-reference-tests`。原生布局仍需隔离应用 smoke：用独立本机 fixture 管理端点分别提供单周、短周期加周、缺重置/参考值、过期重置及 5/10 点差场景，检查窄侧栏、浅/深色、分钟走时与刷新冷却；不连接真实账号，不点击刷新、抢占或重置卡。仅编译应用可用 `./scripts/reload.sh --tag ref-cost-check --build-only`，不替换或重启当前应用。

远端侧栏的私有文件、原子切换、旧操作拒绝及缺失指标回归（macOS；只使用项目 `tmp/` 下的假数据，不需要 app host、凭据或网络）：`./scripts/dev.sh swiftc Sources/Codexpress/{CodexpressSnapshot,CodexpressManagementClient,CodexpressManagementServing,CodexpressManagementError,CodexpressManagementAction,CodexpressOperation,CodexpressResetRequest,CodexpressSessionDelegate}.swift tests/test_codexpress_gateway_cache.swift -o tmp/codexpress-gateway-cache-tests && ./tmp/codexpress-gateway-cache-tests`。

## 本地安装与更新

本地更新入口为 `scripts/update-local.sh`：增量构建 Release，清理开发标记，以固定本地证书签名，并准备一次性安装任务。应用运行期间只暂存更新包，正常退出后在原安装位置原子替换；应用由使用者自行重新打开。更新过程不强退应用、不自动重启，也不联网下载应用更新。

每次替换以“安装成功、清理完成、正式版核验通过”为完成条件；`waiting_for_exit` 仅表示已暂存，不能提前删除待安装包或安装任务。安装后按本轮 tag 精确清理开发包、原始测试包、临时验证文件、失效 socket、旧安装任务和不再需要的验证归档，同时注销测试应用、清理其独立偏好域及系统设置残项。

清理跳过运行中的开发实例，保留最近一次安装回执、源码、未提交修改、固定签名身份、依赖与必要增量构建缓存。不重置正式 cmux／Computer Use 的权限，不清空其他应用的后台或隐私授权；收尾检查实际安装版本、CLI 连通性及测试条目是否消失。

```bash
# 首次创建本地签名证书，仅需一次：
./scripts/dev.sh python3 scripts/local_signing.py init
./scripts/update-local.sh
./scripts/update-local.sh --status
# 复用已验证的项目内 Release 产物，省去重建：
./scripts/update-local.sh --reuse-artifact '<项目内 Release 产物>'
```

签名使用 [rcodesign](https://gregoryszorc.com/docs/apple-codesign/stable/apple_codesign_rcodesign_signing.html) 直接读取 `.cmux/signing/` 中的固定 PEM 证书与无密码私钥，不依赖钥匙串或 Apple 开发者账号。签名文件不提交仓库，应单独备份；文件缺失或身份不匹配时更新停止，不自动生成替代身份。

Computer Use 仅安装随应用提供、且与当前 cmux 使用同一证书签名的 helper，不依赖旧缓存或上游 NIGHTLY、RC 安装。复制后的 helper 仍会验证签名和完整性。

本地证书签名不等同于 Apple 公证。首次从上游、ad-hoc 或其他证书切换时，cmux 及 Computer Use helper 可能需要重新授予隐私权限；后续更新保持同一证书身份。
